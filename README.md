# claude-code-project

- [`medellin-aranjuez/`](medellin-aranjuez/README.md): juego de mundo abierto en tercera persona inspirado en Aranjuez (Medellín). Es un **juego web** (navegador con WebGL 2, instalable como app, funciona sin conexión y con controles táctiles) que se publica en GitHub Pages: https://pablovillamed.github.io/claude-code-project/ una vez activado Pages en el repositorio. También se empaqueta como **app de Windows** (Electron). Guía técnica de la versión web: [`medellin-aranjuez/docs/WEB.md`](medellin-aranjuez/docs/WEB.md).
- [`medellin-unreal/`](medellin-unreal/LEEME.md): traspaso a Unreal Engine 5, **en pausa** (estado y plan en [`TRASPASO.md`](medellin-unreal/TRASPASO.md)).
- [`medellin.code-workspace`](medellin.code-workspace): espacio de trabajo de VS Code con las dos carpetas y las tareas (desarrollo, pruebas, vista como en Pages, app de Windows).
