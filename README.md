# claude-code-project

Configuración de [Claude Code](https://code.claude.com/docs/en/overview)
para trabajar en este repositorio: los marketplaces y plugins que se activan
(`.claude/settings.json`) y el servidor MCP de documentación context7
(`.mcp.json`). El detalle de qué incluye cada uno, cuánto cuesta en contexto y
por qué se configuró así está en [.claude/README.md](.claude/README.md).

Los proyectos que empezaron en ramas de este repositorio tienen ahora el suyo:

- [medellin-aranjuez](https://github.com/PabloVillaMed/medellin-aranjuez): juego
  de mundo abierto en tercera persona inspirado en Aranjuez (Medellín).
- [parche-medellin](https://github.com/PabloVillaMed/parche-medellin): Parche,
  buscador de planes y lugares en Medellín y el Valle de Aburrá.
