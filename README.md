# Medellín: Aranjuez

Juego de mundo abierto en tercera persona inspirado en el barrio Aranjuez
(Comuna 4, Medellín).

- [`medellin-aranjuez/`](medellin-aranjuez/README.md): el juego, hecho con
  Three.js (WebGL 2). Es un **juego web**: corre en el navegador, se instala
  como app, funciona sin conexión y tiene controles táctiles. Se publica en
  GitHub Pages (https://pablovillamed.github.io/medellin-aranjuez/ una vez
  activado Pages en el repositorio) y también se empaqueta como **app de
  Windows** (Electron). Guía técnica de la versión web:
  [`medellin-aranjuez/docs/WEB.md`](medellin-aranjuez/docs/WEB.md).
- [`medellin-unreal/`](medellin-unreal/LEEME.md): el proyecto de Unreal
  Engine 5 para seguirlo en ese motor, **en pausa**. El estado y el plan del
  traspaso están en [`medellin-unreal/TRASPASO.md`](medellin-unreal/TRASPASO.md).
- [`medellin.code-workspace`](medellin.code-workspace): espacio de trabajo de
  VS Code con las dos carpetas y las tareas (desarrollo, pruebas, vista como
  en Pages, app de Windows).
